# Contributing

Thanks for taking an interest. Corrections and small improvements are welcome.

## Found a mistake?

If something looks wrong, such as a figure that does not match what you expect, or confusing wording, please open an issue and pick the template that fits:
https://github.com/The-Pied-Piper/tax-frontend/issues

Tell us the salary, province and year you entered, and what you saw. That is usually enough to look into it.

The figures come from [tax-engine](https://github.com/The-Pied-Piper/tax-engine) and [tax-service](https://github.com/The-Pied-Piper/tax-service). If a figure is wrong, the cause may be in one of those repositories, and we will point you there if so.

## Sending a change

- Keep each pull request to one change.
- Say which issue it deals with, for example `closes #123`, and fill in the pull request template.
- Run `npm run check` before you push. It runs the linter, the format check, the type check and the tests.
- Keep the wording honest: the site gives an estimate, and the copy should say so.

To run the site on your own computer, see [DEVELOPMENT.md](DEVELOPMENT.md).
